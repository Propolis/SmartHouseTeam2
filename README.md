## 🏠 Умный дом на базе IoT

Данный проект — это полнофункциональная система умного дома с поддержкой датчиков, исполнительных устройств и облачного взаимодействия. Код предназначен для управления и мониторинга различных компонентов, интегрирован через MQTT-брокер с возможностью управления как через веб-интерфейс, так и голосом с помощью Яндекс Алисы.  

### 📦 Компоненты системы:

- 🌡️ **Датчик температуры и влажности**
- 🧪 **Датчик газа и дыма MQ-2**
- 💡 **Датчик освещённости**
- 🚶 **Датчик движения HC-SR501**
- 🌧️ **Датчик дождя / протечки MH-RD**
- 🔊 **Зуммер**
- 💧 **Помпа**
- 🔴🟢🔵 **Светодиоды и RGB-лента**
- 🌬️ **Кулеры**
- 🗣️ **Интеграция с Яндекс Алисой**
- 📩 **Система уведомлений через Telegram-бота**

### ⚙️ Архитектура

Основная логика работы всех компонентов системы реализована в файле `main5tgbot.py`. В нём описаны процессы взаимодействия между датчиками, исполнительными модулями, MQTT-брокером и системами уведомлений. Этот файл выступает центральным управляющим узлом всего проекта.  

Проект демонстрирует широкие возможности построения IoT-систем с удалённым управлением, автоматизацией и интеграцией с облачными сервисами.
